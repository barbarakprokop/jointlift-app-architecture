# Security and privacy boundaries

This public companion contains **no real user records or production credentials**. It does not contact Supabase or any other external service. All example participants, tasks and invitations are invented.

The JavaScript examples contain application-style guards for explaining product logic. They **do not implement actual authorization** and must not be used to secure live data. Supabase row level security, account ownership and concurrent writes must be validated independently in the deployed project before any security claims are made.

The original private `jointlift` repository remains private. Do not publish production environment files, full app source, user data, private invitations, authentication tokens or unreleased assets in this repo.

If you spot a security concern, contact via the [portfolio](https://barbarakprokop.com/productdesign/) rather than disclosing private information in a public GitHub issue.
